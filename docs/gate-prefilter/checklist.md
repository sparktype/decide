# 사전 필터 확대 체크리스트

각 항목은 `→ 검증`이 통과해야 체크한다. 코드는 테스트를 먼저 쓴다.

- [ ] 1. 안전 회귀 방지 검사를 먼저 쓴다. 네 세트의 ask·deny 라벨 명령이 규칙·사전 필터로 조용히 건너뛰어지지 않는다. → 검증: 현재(확대 전)에도 통과하는지 확인
- [ ] 2. 사전 필터 표 테스트(건너뛰어야 할 것, 건너뛰면 안 되는 위험 근접 사례, `grep SECRET .env`)를 쓴다. → 검증: 확대 전 기본 목록으로 빨강
- [ ] 3. `.env` 읽기 규칙에 `grep`, `rg`, `jq`를 더한다. → 검증: 표 테스트의 `.env` 항목 초록
- [ ] 4. 기본 사전 필터에 읽기 전용 명령을 더한다. → 검증: 표 테스트와 전체 테스트 초록, 안전 회귀 방지 검사 통과
- [ ] 5. 실제 로그 재생으로 효과를 잰다(새로 건너뛰는 호출 수·비율, 받았던 판정, 절약되는 지연, 사라지는 ask·deny). 새로 건너뛰는 명령 목록을 읽고 위험이 없는지 본다. → 검증: 수치와 목록을 노트에 기록(좋아졌다고 가정하지 않는다)
- [ ] 6. README(사전 필터 설명과 한계), CLAUDE.md, `--show` 확인, 전체 테스트, PR. → 검증: `cargo test` 실패 0, 문서 점검 스크립트
